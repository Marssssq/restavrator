================================================================================
  РУКОВОДСТВО: КАК ДОБАВИТЬ СВОИ ЗВУКИ И МУЗЫКУ В ИГРУ «РЕСТАВРАТОР»
================================================================================

В игре предусмотрена встроенная поддержка добавления и замены звуков!
Если в соответствующей папке есть аудиофайл, игра автоматически воспроизводит его.
Если файла нет — игра использует встроенный процедурный синтез звуков.

--------------------------------------------------------------------------------
1. ГДЕ РАСПОЛОЖЕНЫ ПАПКИ ДЛЯ ЗВУКОВ
--------------------------------------------------------------------------------
Вы можете поместить свои аудиофайлы в ЛЮБУЮ из следующих папок (на ваш выбор):

1) Прямо в папку с игрой / репозиторием:
   C:\vsc\restavrator\Audio\

2) Рядом со скомпилированным файлом Restavrator.exe:
   C:\vsc\restavrator\Build\Audio\

3) Внутри проекта Unity (поддерживает форматы .wav, .mp3, .ogg):
   C:\vsc\restavrator\Assets\Resources\Audio\

--------------------------------------------------------------------------------
2. ИМЕНА АУДИОФАЙЛОВ И ИХ НАЗНАЧЕНИЕ В ИГРЕ
--------------------------------------------------------------------------------
Чтобы игра поняла, за какое действие отвечает файл, назовите его в точности
как указано в таблице ниже (расширение .wav):

| Имя файла             | Назначение в игре                                       |
|-----------------------|---------------------------------------------------------|
| secret.wav            | Нахождение скрытого тайника в изделии (пружина/защелка) |
| classical_theme.wav   | Фоновая классическая музыка мастерской (зациклена)     |
| purr.wav              | Мурчание кота Барсика при поглаживании                  |
| bell.wav              | Колокольчик на входной двери / новые заказы             |
| step.wav              | Шаги реставратора по мастерской                         |
| click.wav             | Щелчок пинцета и точечных креплений                     |
| reset.wav             | Сброс механизма / отскок пружины                        |
| grind.wav             | Звук механической шлифовки (зациклен)                   |
| clean.wav             | Звук химической чистки щеткой (зациклен)                |
| coin.wav              | Звон золотых монет при сдаче заказа в кассу             |
| fail.wav              | Звук брака / повреждения изделия                        |
| clock.wav             | Тиканье старинного хронометра Буре                      |
| chime.wav             | Хрустальный перезвон завершения полировки               |
| switch.wav            | Звук выбора инструмента на панели                       |
| hearth.wav            | Потрескивание дров в камине мастерской                  |

--------------------------------------------------------------------------------
3. ФОРМАТ АУДИОФАЙЛОВ
--------------------------------------------------------------------------------
• Рекомендуемый формат для внешних папок (Audio / Build\Audio):
  WAV (PCM 16 бит или 8 бит, 44100 Гц, Моно или Стерео).
  Этот формат игра загружает мгновенно напрямую с диска без задержек.

• Если вы добавляете звуки через Unity Editor в Assets\Resources\Audio\:
  Поддерживаются форматы: .wav, .mp3, .ogg.
  Unity сам автоматически сконвертирует их при сборке.

--------------------------------------------------------------------------------
4. КАК БЫСТРО ЗАМЕНИТЬ ЗВУК ТАЙНИКА (ПРИМЕР)
--------------------------------------------------------------------------------
1. Найдите любой понравившийся звук (например, таинственный щелчок старинной шкатулки,
   лязг секретного замка или загадочный звон).
2. Назовите файл:
   secret.wav
3. Положите файл в папку:
   C:\vsc\restavrator\Audio\secret.wav
   (или в C:\vsc\restavrator\Build\Audio\secret.wav)
4. Запустите игру. При обнаружении скрытого тайника прозвучит именно ваш звук!

--------------------------------------------------------------------------------
5. КАК ВЕРНУТЬ СТАНДАРТНЫЙ ЗВУК
--------------------------------------------------------------------------------
Просто удалите или переименуйте свой файл из папки Audio.
Игра сразу же вернется к родному процедурному звучанию.
